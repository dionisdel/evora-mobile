# Assets de Evora Mobile

Colocar aquí:

- `icon.png` — Icono de la app (1024x1024px, PNG sin transparencia para iOS)
- `adaptive-icon.png` — Icono adaptivo Android (1024x1024px, fondo transparente)
- `splash.png` — Splash screen (1284x2778px, logo Evora centrado)
- `favicon.png` — Favicon para web (48x48px)

## Colores de marca
- Fondo principal: #1a2332 (azul oscuro)
- Acento: #3182ce (azul)
- Texto: #ffffff (blanco sobre fondos oscuros)

## Generador de assets
Se pueden generar automáticamente con:
```bash
npx expo-asset-utils generate-icons ./assets/icon-source.png
```
